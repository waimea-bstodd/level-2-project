# Project Final Review and Reflection

## Addressing Relevant Implications

### Usability

To make the app easy to use, I implemented a consistent navigation bar across all pages so users can easily move around the application without getting lost

### End User

The app was designed around the real household need to stream downloaded music across multiple devices on the same Wi-Fi without duplicating files, keeping text and features simple for everyone to use.


### Aesthetics

I aimed for a clean visual style using a consistent font and color theme. While I initially experimented with frosted glass blur effects, I ultimately chose a clean white background because it looked simpler and cleaner. I also realized I should have focused more on mobile design since smaller screens can cause header text to warp.


### Accessibility

To support accessibility, the clean layout makes text easy to read, and using standard web controls ensures the music player can be interacted with smoothly across different devices.

### Intellectual Property

Since the application deals with local audio files, a reminder notice was included on the upload form advising users not to pirate music and to support artists by purchasing their work.
