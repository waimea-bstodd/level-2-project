# Project Final Review and Reflection

## Addressing Relevant Implications

### UI Design

When I first started working on the UI Design of the app/website I wanted it to end up having a frosted blur effect. After getting it to work I decided to not really use it as I think the white background made the UI look more clean and simple. I also think that when I was working on the UI I should of focused more of the design on mobile devices since when you use the music player on a smaller device such as the iPhone 12 Mini the text on the header warps to the next line and it makes the UI feel more bloated and more unprofessional

### Usability

To make the app easy to use, I implemented consistent navigation across all pages


### End User

The app was designed around the real household need to stream downloaded music across multiple devices without duplicating files, keeping text and features simple for everyone to use.


### Aesthetics

I aimed for a clean visual style using a consistent font and color theme. While I experimented with frosted glass effects, I chose a clean white background because it looked simpler and cleaner
